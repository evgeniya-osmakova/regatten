# Data model

This document describes the database architecture for the Optimist B regatta importer MVP.

The model should stay small and normalized.

Do not store raw DODV JSON.

Do not store raw Manage2Sail JSON unless explicitly requested later.

Do not create extra tables for clubs, seasons, regions, or classes in the MVP.

## Overview

Core tables:

```text
Regatta
Sailor
RegattaSailorResult
RaceResult
```

Relationships:

```text
Regatta 1 ── many RegattaSailorResult
Sailor 1 ── many RegattaSailorResult
RegattaSailorResult 1 ── many RaceResult
```

## Regatta

One row is one DODV Optimist B regatta.

Fields:

```ts
id: string
year: number
level: string
regionName: string

name: string
dateFrom: Date
dateTo: Date
location?: string

canceled: number
boats: number

clubNameFull?: string
clubNameShort?: string

runsTotal?: number
runsScored?: number
factor?: number

resultLink?: string
vereinUrl?: string

eventId?: string
classId?: string

isCompleted: boolean
resultImportStatus: ResultImportStatus

createdAt: Date
updatedAt: Date
```

Notes:

- `id` is the DODV id, for example `2026B032`.
- `eventId` is the Manage2Sail event id from `window.SailingInfo.eventId`.
- `classId` is the Manage2Sail class id/string from the `resultLink`.
- Do not store `manage2sailResultApiUrl`; it is computed from `eventId` and `classId`.
- Do not store `manage2sailSlugOrId`; it can be parsed again from `resultLink`.
- Do not store raw DODV JSON.

Suggested Prisma model:

```prisma
model Regatta {
  id                 String @id

  year               Int
  level              String
  regionName         String

  name               String
  dateFrom           DateTime
  dateTo             DateTime
  location           String?

  canceled           Int
  boats              Int

  clubNameFull       String?
  clubNameShort      String?

  runsTotal          Int?
  runsScored         Int?
  factor             Float?

  resultLink         String?
  vereinUrl          String?

  eventId            String?
  classId            String?

  isCompleted        Boolean
  resultImportStatus ResultImportStatus @default(NOT_STARTED)

  sailorResults      RegattaSailorResult[]

  createdAt          DateTime @default(now())
  updatedAt          DateTime @updatedAt

  @@index([year])
  @@index([regionName])
  @@index([isCompleted])
  @@index([resultImportStatus])
}
```

## Sailor

One row is one observed sailor identity.

A sailor identity is based on the combination of normalized sailor name and normalized sail number.

Fields:

```ts
id: string
identityKey: string
name: string
normalizedName: string
sailNumber: string
sailNumberNormalized: string
clubName?: string
clubCode?: string
createdAt: Date
updatedAt: Date
```

Notes:

- `id` is generated by the application/database.
- `identityKey` is unique.
- Build `identityKey` from `normalizedName` and `sailNumberNormalized`.
- Example: `lina baumann|ger12605`.
- If sail number is missing, use a stable fallback based on normalized name and club code.
- `clubName` and `clubCode` are the latest known club values.
- Since sailors may change clubs, also store club data on each regatta result row.

Suggested Prisma model:

```prisma
model Sailor {
  id                   String @id @default(cuid())

  identityKey           String @unique
  name                  String
  normalizedName        String
  sailNumber            String
  sailNumberNormalized  String

  clubName              String?
  clubCode              String?

  results               RegattaSailorResult[]

  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt

  @@index([normalizedName])
  @@index([sailNumberNormalized])
}
```

## RegattaSailorResult

One row is one sailor's overall result in one regatta.

Fields:

```ts
id: string
regattaId: string
sailorId: string

rank?: number
totalPoints?: number
netPoints?: number

clubName?: string
clubCode?: string

createdAt: Date
updatedAt: Date
```

Notes:

- `regattaId` references `Regatta.id`.
- `sailorId` references `Sailor.id`.
- Enforce uniqueness on `(regattaId, sailorId)`.
- `totalPoints` maps from Manage2Sail `TotalPoints`.
- `netPoints` maps from Manage2Sail `NetPoints`.
- Store club data here too because a sailor may change clubs over time.

Suggested Prisma model:

```prisma
model RegattaSailorResult {
  id             String @id @default(cuid())

  regattaId      String
  regatta        Regatta @relation(fields: [regattaId], references: [id], onDelete: Cascade)

  sailorId       String
  sailor         Sailor @relation(fields: [sailorId], references: [id])

  rank           Int?
  totalPoints    Float?
  netPoints      Float?

  clubName       String?
  clubCode       String?

  raceResults    RaceResult[]

  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt

  @@unique([regattaId, sailorId])
  @@index([sailorId])
  @@index([rank])
  @@index([clubCode])
}
```

## RaceResult

One row is one sailor's result in one race of one regatta.

Fields:

```ts
id: string
regattaSailorResultId: string

raceIndex: number
rank?: number
points?: number
pointsDiscarded: boolean
raceStatusCode?: string

createdAt: Date
updatedAt: Date
```

Notes:

- `regattaSailorResultId` references `RegattaSailorResult.id`.
- Enforce uniqueness on `(regattaSailorResultId, raceIndex)`.
- `raceIndex` maps from Manage2Sail `OverallRaceIndex`.
- `points` maps from Manage2Sail `Points`.
- `pointsDiscarded` maps from Manage2Sail `PointsDiscarded`.
- `raceStatusCode` maps from Manage2Sail `RaceStatusCode`, for example `DNF`.

Suggested Prisma model:

```prisma
model RaceResult {
  id                      String @id @default(cuid())

  regattaSailorResultId    String
  regattaSailorResult      RegattaSailorResult @relation(fields: [regattaSailorResultId], references: [id], onDelete: Cascade)

  raceIndex                Int
  rank                     Int?
  points                   Float?
  pointsDiscarded          Boolean @default(false)
  raceStatusCode           String?

  createdAt                DateTime @default(now())
  updatedAt                DateTime @updatedAt

  @@unique([regattaSailorResultId, raceIndex])
  @@index([raceStatusCode])
}
```

## ResultImportStatus

Suggested Prisma enum:

```prisma
enum ResultImportStatus {
  NOT_STARTED
  SKIPPED_NOT_COMPLETED
  IMPORTED
  MISSING_RESULT_LINK
  EVENT_ID_UNRESOLVED
  RESULT_FETCH_FAILED
  INVALID_RESULT_JSON
  NO_ENTRIES
}
```
